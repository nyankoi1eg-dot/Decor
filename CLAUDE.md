# Decor

## Estilo de respuesta: caveman por defecto

Al inicio de cada sesión, activa el skill `caveman` (nivel **full**) y mantenlo
durante toda la sesión, sin anunciarlo.

- Responde siempre en español (el skill conserva el idioma del usuario).
- Términos técnicos, código, nombres de API, comandos y mensajes de error van
  verbatim, sin comprimir.
- Para cambiar de nivel: `/caveman lite|full|ultra`.
- Para desactivarlo en una sesión concreta: "stop caveman" o `/caveman off`.
